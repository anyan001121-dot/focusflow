# FocusFlow

**开始不了时，先找一小步。被打断以后，留一个能回来的地方。**

文档开了很久，第一句话还没写；好不容易开始，又被一条消息带走。FocusFlow 想在这些时刻帮一点忙：写下眼前的事，看一个下一步，需要离开时保存位置。

你不用把想法整理好才来，也不需要先证明自己能坚持。

[直接打开浏览器版](try/) · [README 与源代码](https://github.com/anyan001121-dot/focusflow) · [使用前与使用后](before-after.md)

浏览器版打开就能用。在桌面上，左边是待接回，中间是眼前任务，右边是念头口袋和回看。任务、草稿和回顾都保存在当前浏览器里。

## 可以怎样用？

- **开始：** 写下一件事，先做一个能动手的小步骤。
- **切换：** 把另一件事放进念头口袋，需要现在做就点「先做这件」。回来还能接上原来的步骤。
- **回顾：** 结束任务时看一眼已经完成的小步，也可以留一句「下次试试」。

用任务树找子任务和书签，也可以选几件事一起汇总。默认用离线模板，需要时再连接自己的 AI。[工作台使用说明](workbench-roadmap.md)

## A small next step. A place to come back to.

For study or work that feels hard to start, FocusFlow offers one suggested step, a place to park another thought, and a saved point to return to after a break. You can use only the parts that help.

The browser workbench saves tasks and drafts in the current browser and works with offline templates. An optional AI endpoint receives task text when you ask it for a first step. FocusFlow does not diagnose or treat ADHD.
