# 2026-11-06 更新

首页：**想做什么？从一小步开始。** 写下你想做的事，让 FocusFlow 帮你看看从哪里开始。

- 用统一的矢量小芽、路径插画与线性操作图标替换界面 emoji，保留「出发咯」。
- 记录念头直接保存，不再因内容包含「继续」「完成了」而触发任务操作。
- 暂停后可保存到「待接回」，去做另一件事，回来时保留步骤、完成记录与备注。
- 支持修改动作与完成标准，以及关键操作的一次撤销。清空数据需明确确认。
- 不知道怎么做或缺材料时，可先插入准备动作，完成后返回原步骤。
- 一组步骤做完后可以填写下一步，延续原目标和进度。
- 侧栏可下载进度文件，下次上传恢复；预览后加入待接回，不覆盖当前任务，重复导入会去重。
- 当前步骤使用淡绿色卡片，完成标准更清晰，已完成记录和计时放在次要位置。

## 验证和边界

68 项本地测试通过，覆盖误触发、撤销、任务切换、跨会话文件恢复和界面操作。桌面和手机视觉在开发期间检查过。真实用户试用尚未开展。

进度文件包含任务文本，需要自己保管；文件恢复是手动备份，不是自动云同步。公网访客离开前应下载备份。本地单用户模式继续通过 SQLite 保存进度。

离线建议使用模板，尚未验证付费模型的真实输出质量。撤销保留原始事件日志，分析原始事件时需考虑撤销，不能直接把事件次数当成完成率。
